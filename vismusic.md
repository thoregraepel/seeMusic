Project seeMusic aims to create a web app that allows the user to play midi files alongside a visual representation of the music.
The representation is given by a vertical grating that changes with the music. Its spatial frequency represents the frequency of the currently played note. If multiple notes are played at the same time, the gratings are superimposed to reveal moire type patterns. 
The app offers a number of test midi files for experimentation.
There is an option to superimpose a reference grating corresponding to the key of the music being played.
Audio and visual representation can be toggled on and off.
